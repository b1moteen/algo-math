# Алгоритмы

Одна папка — одна тема: `two_pointers/`, `binary_search/`, `prefix_sums/`… Внутри — папка на задачу:

```
algorithms/two_pointers/lc_0011_container/
  README.md     # источник + условие своими словами + идея одной фразой + сложность O(·)
  solution.py
  tests/1.in, 1.out   # примеры из условия + свой крайний случай
```

Задачи с LeetCode оформляй так же: решение в формате stdin/stdout не обязательно, но идея и сложность в README — обязательно.
