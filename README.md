# algo-math

Мой тренировочный репозиторий: алгоритмы на Python, математика (вероятность → матанализ → линейная алгебра → статистика), pandas и SQL.
Цели: Академия аналитиков Авито (лето 2027), экзамен ИТМО AI Talent Hub, стажировки DS/аналитика, ШАД-2028.

**Главное правило: всё здесь написано руками.** ИИ — только репетитор: намёк → метод → псевдокод. Код решений ИИ не пишет (см. `CLAUDE.md`).

## Структура

| Папка | Что внутри |
|---|---|
| `placement/` | входной тест (03.10.2026): 6 задач + математическая разминка |
| `algorithms/<тема>/<задача>/` | решения задач: `solution.py`, `tests/`, короткий `README.md` (условие своими словами + идея + сложность) |
| `math/<раздел>/` | решения задач по математике в Markdown: условие → решение → ответ |
| `sim/` | ноутбуки и скрипты: проверяю ответы задач по вероятности симуляцией Монте-Карло |
| `pandas/`, `sql/` | задачи по данным: одна задача — два решения, на pandas и на SQL |
| `tools/check.py` | проверка решения на тестах |

## Запуск

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python3 tools/check.py placement/01_top_words
```

Своя задача с тестами: создай `algorithms/<тема>/<задача>/tests/1.in` и `1.out` — и проверяй тем же `check.py`.

## Правила
1. Сначала сам 15 минут. Застрял → подсказка 1 (идея) → ещё 10 минут → подсказка 2 (метод) → псевдокод.
2. Посмотрел разбор → через 48 часов решаю заново с пустого файла (воскресная «дорешка»).
3. В `README.md` задачи — идея одной фразой и сложность O(·). Не могу объяснить — задача не решена.
4. Коммит после каждой сессии: `тема: что решил`.
