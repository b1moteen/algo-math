# 4. Самый длинный отрезок
*Два указателя. Это уже не «Поколение Python», а первая настоящая алгоритмическая задача.*

В первой строке — `n` и `S` (1 ≤ n ≤ 2·10⁵, 0 ≤ S ≤ 10¹⁴). Во второй — `n` **неотрицательных** целых чисел, каждое ≤ 10⁹.

Найди длину самого длинного **непрерывного** отрезка массива, сумма которого не больше `S`. Если такого нет, выведи `0`.

| Ввод | Вывод |
|---|---|
| `5 7`<br>`2 1 3 4 1` | `3` (отрезок `2 1 3`) |
| `3 0`<br>`1 2 3` | `0` |

Лимит — 2 секунды. Решение за O(n²) не пройдёт большие тесты — это нормально: так ты и узнаешь, что нужна идея.
