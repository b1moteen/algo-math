# 6. Сколько раз встречается
*Бинарный поиск.*

В первой строке — `n` (1 ≤ n ≤ 2·10⁵). Во второй — `n` целых чисел, **отсортированных по неубыванию**. В третьей — `q` (1 ≤ q ≤ 2·10⁵). В четвёртой — `q` запросов `x`.

Для каждого запроса выведи, сколько раз `x` встречается в массиве. Ответы — в одну строку через пробел.

| Ввод | Вывод |
|---|---|
| `6`<br>`1 2 2 2 5 7`<br>`5`<br>`2 3 7 0 8` | `3 0 1 0 0` |

Нельзя: модуль `bisect`, `Counter`, словарь и `list.count` — двоичный поиск пишешь сам. (Со словарём задача решается в одну строку, но на собеседовании спросят именно бинпоиск.)
Лимит — 2 секунды.
