# 1. Частые слова
*Строки, словари, сортировка с ключом.*

В первой строке — число `k` (1 ≤ k ≤ 100). Во второй — текст до 10⁵ слов из строчных латинских букв, слова разделены пробелами.

Выведи `k` самых частых слов в формате `слово количество`, по одному на строку. Порядок: по убыванию частоты, при равенстве — по алфавиту. Если различных слов меньше `k`, выведи все.

| Ввод | Вывод |
|---|---|
| `2`<br>`the cat and the dog and the bird` | `the 3`<br>`and 2` |
| `3`<br>`b a c a b d` | `a 2`<br>`b 2`<br>`c 1` |
