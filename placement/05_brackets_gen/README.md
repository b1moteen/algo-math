# 5. Все правильные скобочные последовательности
*Рекурсия, перебор с отсечением.*

Дано `n` (1 ≤ n ≤ 7). Выведи все правильные скобочные последовательности из `n` пар круглых скобок, по одной на строку, **в лексикографическом порядке** (считаем, что `(` < `)`).

| Ввод | Вывод |
|---|---|
| `3` | `((()))`<br>`(()())`<br>`(())()`<br>`()(())`<br>`()()()` |

Нельзя: `itertools`. Подсказка уровня 0: перебирать все 2²ⁿ строк и проверять каждую — можно, но красивее строить только правильные.
